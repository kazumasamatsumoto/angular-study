# 応用編（Advanced） - Angular Routing

このセクションでは、Angular Routingの上級レベルの概念と実践的な実装パターンを学びます。

## 学習内容

### 1. 遅延ローディング（Lazy Loading）
- 機能モジュールの遅延ローディング
- `loadChildren` による動的インポート
- 遅延ローディングされたモジュールの構造
- ルートガードとの組み合わせ
- パフォーマンス最適化

### 2. カスタムルートマッチング（Custom Route Matching）
- `matcher` 関数によるカスタムルートマッチング
- 複雑なURLパターンの処理
- カスタムマッチャーの実装
- 動的ルート生成との組み合わせ

### 3. プリロード戦略（Preloading Strategies）
- デフォルトのプリロード戦略
- `PreloadAllModules` の使用方法
- カスタムプリロード戦略の実装
- データ駆動型プリロード（Data-driven Preloading）
- ネットワーク状態に基づくプリロード

### 4. ルーティングのテスト（Testing Routing）
- ルーティングのユニットテスト
- ルートガードのテスト
- ナビゲーションのテスト
- `RouterTestingModule` の使用方法
- 統合テストでのルーティングテスト

### 5. 動的ルート生成（Dynamic Route Generation）
- 実行時におけるルートの動的追加
- `resetConfig()` によるルート設定の変更
- 設定ベースのルーティング
- 権限に基づく動的ルート生成
- プラグインアーキテクチャでのルーティング

### 6. 複雑なルートガードの組み合わせ（Complex Guard Combinations）
- 複数のガードの実行順序
- 非同期ガードの処理
- ガード間のデータ共有
- エラーハンドリングとフォールバック
- 条件分岐を伴うガードロジック

### 7. 名前付きアウトレットとセカンダリルート（Named Outlets and Secondary Routes）
- 複数の `router-outlet` の管理
- メインルートとセカンダリルートの共存
- サイドパネルやモーダルとの統合
- セカンダリルートのナビゲーション
- 名前付きアウトレットのクリア

### 8. ルートの再利用とコンポーネントの最適化（Route Reuse Strategy）
- `RouteReuseStrategy` の実装
- コンポーネントの再利用によるパフォーマンス向上
- タブナビゲーションでの活用
- メモリ管理とライフサイクル

### 9. 深いリンクとフラグメント（Deep Linking and Fragments）
- フラグメント（ハッシュ）の使用
- ページ内スクロールとの連携
- ブックマーク可能なURLの生成
- ブラウザの履歴との統合

### 10. ルーティングアニメーション（Routing Animations）
- ルート遷移時のアニメーション
- `@angular/animations` との統合
- 遷移状態の管理
- 複雑なアニメーションパターン

### 11. 国際化とルーティング（i18n Routing）
- 言語プレフィックスを含むルート
- ロケールに基づくルーティング
- 動的言語切り替え
- SEO対応の多言語ルーティング

### 12. エラーハンドリングとフォールバック（Error Handling）
- ルーティングエラーの処理
- 404エラーページの実装
- エラーロギングとモニタリング
- グロースエラーハンドラー
- リトライメカニズム

### 13. パフォーマンス最適化（Performance Optimization）
- ルートのコード分割
- バンドルサイズの最適化
- プリロードの最適化
- ルートのキャッシング戦略
- メモリリークの防止

### 14. ルーティングと状態管理（Routing and State Management）
- NgRx/状態管理との統合
- ルート状態の管理
- ナビゲーションアクションの処理
- URLとアプリケーション状態の同期

## 実装例の構造

```
03-advanced/
├── lazy-loading/              # 遅延ローディング
├── custom-matchers/           # カスタムルートマッチング
├── preloading-strategies/     # プリロード戦略
├── testing/                   # ルーティングのテスト
├── dynamic-routes/            # 動的ルート生成
├── complex-guards/            # 複雑なガードの組み合わせ
├── named-outlets/             # 名前付きアウトレット
├── route-reuse/               # ルート再利用戦略
├── deep-linking/              # 深いリンク
├── routing-animations/        # ルーティングアニメーション
├── i18n-routing/              # 国際化とルーティング
├── error-handling/            # エラーハンドリング
├── performance/               # パフォーマンス最適化
└── state-management/          # 状態管理との統合
```

## 学習目標

このセクションを完了すると、以下のことができるようになります：

- ✅ 大規模アプリケーションでの遅延ローディングを実装できる
- ✅ カスタムルートマッチングで柔軟なルーティングができる
- ✅ 適切なプリロード戦略を選択・実装できる
- ✅ ルーティングに関する包括的なテストを書ける
- ✅ 実行時にルートを動的に生成・変更できる
- ✅ 複雑なガードロジックを適切に組み合わせられる
- ✅ 名前付きアウトレットを使用して複雑なUIを実装できる
- ✅ ルート再利用戦略でパフォーマンスを最適化できる
- ✅ ルーティングアニメーションを実装できる
- ✅ 多言語対応のルーティングを実装できる
- ✅ エラーハンドリングとフォールバックを適切に実装できる
- ✅ ルーティングと状態管理を統合できる
- ✅ 本番環境レベルのパフォーマンス最適化ができる

## 実践的なプロジェクト例

- **Eコマースサイト**: 商品カテゴリ、検索、フィルタリング、カート
- **ダッシュボードアプリ**: 多段階の認証、権限管理、動的メニュー
- **CMS**: 動的コンテンツルート、プレビューモード、エディター
- **SNSアプリ**: 無限スクロール、リアルタイム更新、深いリンク
