# Angular Routing 学習リポジトリ

Angular Routingについて、基礎から応用まで体系的に学べるリポジトリです。

## 📚 学習コース構成

このリポジトリは、3つのレベルに分かれており、段階的にAngular Routingを習得できるよう設計されています。

### 🟢 01-basic（基礎編）

Angular Routingの基礎的な概念と機能を学びます。

**主な学習内容:**
- ルーティングの基本設定
- ナビゲーション方法（`routerLink`、`router.navigate()`）
- ルートパラメータとクエリパラメータ
- 基本的なルート設定（リダイレクト、ワイルドカード）
- ネストされたルートの基礎

詳細は [01-basic/README.md](./01-basic/README.md) を参照してください。

### 🟡 02-intermediate（発展編）

Angular Routingの中級レベルの概念と実装方法を学びます。

**主な学習内容:**
- ルートガード（CanActivate, CanDeactivate, Resolve, CanLoad）
- ActivatedRoute の詳細な使用方法
- ルートデータとメタデータ
- 複雑なリダイレクトロジック
- 高度なネストされたルート
- ルートイベントの監視
- Observable パターン

詳細は [02-intermediate/README.md](./02-intermediate/README.md) を参照してください。

### 🔴 03-advanced（応用編）

Angular Routingの上級レベルの概念と実践的な実装パターンを学びます。

**主な学習内容:**
- 遅延ローディング（Lazy Loading）
- カスタムルートマッチング
- プリロード戦略
- ルーティングのテスト
- 動的ルート生成
- 複雑なルートガードの組み合わせ
- 名前付きアウトレットとセカンダリルート
- ルート再利用戦略
- ルーティングアニメーション
- 国際化とルーティング
- エラーハンドリング
- パフォーマンス最適化
- 状態管理との統合

詳細は [03-advanced/README.md](./03-advanced/README.md) を参照してください。

## 🚀 使い方

1. 各ディレクトリのREADMEを読んで、学習内容を確認します
2. 各セクションのサンプルコードを実行しながら学習します
3. 実践的な例を通じて理解を深めます
4. 演習問題に取り組んで知識を定着させます

## 📋 前提知識

- TypeScript の基礎知識
- Angular の基本概念（コンポーネント、モジュール、サービス）
- RxJS の基礎（Observable, Subject など）
- JavaScript/TypeScript での非同期処理

## 🛠️ 技術スタック

- **Angular**: v20
- **TypeScript**: 最新版
- **RxJS**: Angular に含まれるバージョン

## 📖 学習の進め方

### 推奨学習順序

1. **基礎編**を完璧に理解する
   - ルーティングの基本をしっかり身につける
   - 各概念を実際にコードを書いて確認する

2. **発展編**で実用的な機能を学ぶ
   - ルートガードは特に重要なので、すべての種類を理解する
   - 実際のアプリケーションでよく使うパターンを練習する

3. **応用編**で高度な技術を習得する
   - 大規模アプリケーションで必要となる技術を学ぶ
   - パフォーマンス最適化やテストについても理解を深める

### 学習のコツ

- **実際にコードを書く**: 読むだけでなく、必ず手を動かして実装してみる
- **エラーを恐れない**: エラーから学ぶことは多い
- **公式ドキュメントを参照する**: Angular の公式ドキュメントと併せて学習する
- **プロジェクトを作成する**: 学習した内容を組み合わせて小さなプロジェクトを作成する
